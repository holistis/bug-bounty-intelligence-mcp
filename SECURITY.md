# Security policy

## Reporting a vulnerability

Please report security problems privately and not in a public issue.

Use GitHub private vulnerability reporting for this repository:
https://github.com/holistis/bug-bounty-intelligence-mcp/security/advisories/new

Say what you found, which version or commit you tested, and how to reproduce it. A proof of concept helps but is not required.

## What to expect

- An acknowledgement within 7 days.
- A first assessment within 30 days.
- A fix, or a clear explanation of why there is none, and coordinated disclosure. 90 days is the default and we agree another date with you when that is needed.
- Credit in the advisory if you want it.

## Scope

This repository only. Problems in a dependency belong to that project, and we want to hear about them as well when they affect this one.

## Supported versions

The latest release and the default branch.
